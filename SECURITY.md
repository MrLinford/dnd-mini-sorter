# Security Policy

## Supported Versions

Since this is a lightweight utility script designed for local automation on private servers (such as Unraid), security updates are provided for the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project (such as a path traversal risk, unsafe file handling, or unintended behaviour in the sorting logic), please report it responsibly.

* **Do not** open a public GitHub issue for security vulnerabilities.
* Instead, please reach out by opening a confidential discussion or by contacting the repository owner directly through GitHub.

Please provide a detailed description of the vulnerability, steps to reproduce it, and any potential impact. We will review the report and work on a fix promptly.
